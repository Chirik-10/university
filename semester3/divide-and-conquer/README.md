# Лабораторная работа "Разделяй и влавствуй"

## Задание
### Часть 1: сортировка
1. Реализовать сортировку слиянием или быструю сортировку (по выбору; функция sort). Сортируется массив (vector) элементов, тип элементов - целые числа.
2. Проверить корректность реализации на приложенных юнит-тестах.
3. Замерить время работы алгоритма на массивах случайных чисел разного размера (N=10, 100, 1000 и т.д.), сравнить со временем работы стандартной сортировки std::sort на тех же массивах (если сортировка изменяет входной массив, создавать его копию перед сортировкой и сортировать копию).

### Часть 2: задача поиска ближайших точек
1. Требуется реализовать функцию поиска пары ближайших точек в 2-мерном пространстве (функция closest_pair). На вход функция принимает массив точек (каждая точка задается двумя вещественными координатами x и y), на выходе она должна вернуть пару ближайших (по расстоянию) точек; порядок точек в паре значения не имеет.
2. Реализовать алгоритм полного перебора: полный перебор всех возможных пар точек и выбор ближайшей пары.
3. Реализовать алгоритм “разделяй и властвуй” (см. описание ниже; для требующейся в алгоритме сортировки нужно использовать эффективную реализацию, например, std::sort).
4. Проверить корректность реализации на прилагающихся юнит-тестах.
5. Замерить время работы двух алгоритмов на массивах случайных точек разного размера (N=10, 100, 1000 и т.д.; использовать одинаковые входные данные для каждого алгоритма).
