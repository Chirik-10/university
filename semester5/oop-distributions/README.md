# Лабораторная работа "Статистические распределения"

## Что делает программа
Работа с вероятностными распределениями (Пирсона типа VII):
- Вычисление плотности в точке
- Расчёт числовых характеристик (матожидание, дисперсия, асимметрия, эксцесс)
- Генерация случайных величин
- Построение смесей распределений
- Эмпирическое распределение по выборке
- Визуализация результатов (Python)

## Структура проекта
lab1-structural/ - Структурный подход

lab2-class-basic/ - Класс Primary для основного распределения

lab3-class-mixture-empiric/ - Классы Mixture и Empiric (композиция, динамическая память)

lab4-interfaces-template/ - Интерфейсы IDistribution/IPersistent, шаблонный Mixture
