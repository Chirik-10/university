# Лабораторная работа 2 (класс Primary)

## Задание
Модифицировать программу, разработанную в лабораторной работе №1, так чтобы в ней был определен класс, реализующий основное распределение. 

2.1. Определить ответственность класса. Ввод-вывод следует производить вне функций класса.

2.2. Определить атрибуты, необходимые для реализации класса. Обязательные атрибуты: параметры сдвига, масштаба и формы. Целесообразно использовать также вспомогательные атрибуты, важные для обеспечения эффективности вычисления плотности и моделирования случайной величины. Поместить атрибуты в закрытую часть описания.

2.3. Определить функции, обеспечивающие поведение класса. Выделить интерфейс класса и поместить его в открытую часть описания. Обязательная часть интерфейса: 

2.3.1) конструкторы (в том числе инициализация данными из файла);

2.3.2) функции, изменяющие значения обязательных атрибутов, например set-функции;

2.3.3) функции, возвращающие значения обязательных атрибутов, например get-функции;

2.3.4) функция для вычисления значений плотности распределения по заданному аргументу;

2.3.5) функция для вычисления математического ожидания, дисперсии, коэффициентов асимметрии и эксцесса;

2.3.6) функция для моделирования случайной величины;

2.3.7) функции, обеспечивающие персистентность объекта: сохранение значений (обязательных или всех) атрибутов в файле и считывание их из файла; файлы для сохранения и считывания (в том числе, конструктором) должны иметь единый формат.

2.4. Объекты всегда должны находиться в корректном состоянии. При возникновении ошибок (например, нарушение ограничений на значения параметров) необходимо генерировать исключительные ситуации, а их обработку осуществлять вне функций-членов класса.

2.5. Разработать функцию (функции), тестирующую возможности класса. Поместить описание класса в один файл, реализацию класса – в другой, а тестирующую функцию – в третий.

## Файлы
- primary.h/cpp - Класс Primary
- distribution.h/cpp - Структурная версия
- tests.cpp - Тестирование
- main.cpp - Демонстрация
