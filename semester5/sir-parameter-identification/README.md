# Учебная практика (ознакомительная): Исследование и сравнение двух подходов к решению обратной задачи оценки параметров модели SIR - классического (метод Нелдера-Мида) и нейросетевого (PINN)

## О проекте
В рамках практики выполнено сравнение двух подходов к оценке параметров эпидемиологической модели SIR:

| Подход | Метод | Тип |
|--------|-------|-----|
| Классический | Метод Нелдера-Мида + численное интегрирование ОДУ | Детерминированный |
| Нейросетевой | Physics-Informed Neural Network (PINN) | Машинное обучение |

PINN взят из открытого репозитория: [ODE-PINN by AmerFarea](https://github.com/AmerFarea/ODE-PINN) для сравнительного анализа.

Цель: сравнить точность, устойчивость и применимость подходов к синтезированным и реальным эпидемиологическим данным.

## Моя реализация (классический подход):
1. Численное решение системы ОДУ (метод Рунге-Кутты 4-го порядка, `scipy.integrate.solve_ivp`)
2. Функция потерь - среднеквадратичная ошибка между модельными и реальными данными
3. Оптимизация методом Нелдера-Мида (`scipy.optimize.minimize`)
4. Эксперименты:
- На синтезированных данных (с известными beta=0.5, gamma=0.05)
- На реальных данных по COVID-19 в Италии (24.02-25.03.2020)
