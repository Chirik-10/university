# Лабораторная работа "Интерфейс с языком C++"

## Задание
Написать процедуру на языке Ассемблера, реализующую формирование сжатой строки символов (сжатие заключается в удалении повторного вхождения символов из исходной строки при просмотре ее слева направо) с использованием цепочечных команд. Написать вызывающую функцию на языке С++, осуществляющую ввод исходных данных и вывод результатов. Для вызова процедуры использовать соглашение о вызовах stdcall.
