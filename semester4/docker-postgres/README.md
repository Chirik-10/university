# Лабораторная работа "Создание контейнера docker. Работа с docker-compose."

## Задание
Изучение синтаксиса Dockerfile и написание docker-compose файла, содержащего два сервиса: один для клиент-серверного приложения, а второй - для базы данных. Дополнительно необходимо настроить возможность подключение с личного компьютера к приложению, запущенному на виртуальной машине, и проверить корректность его работы.
